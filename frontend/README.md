# AyudaMapa 🌍

Plataforma de coordinación y distribución de ayudas humanitarias durante emergencias en Colombia.

## 🚀 Características

- 📍 **Mapa interactivo** con marcadores de necesidades y puntos de ayuda
- 🔴 **Sistema de prioridades** automático basado en urgencia
- 📊 **Dashboard** con estadísticas en tiempo real
- 🔐 **Sistema de autenticación** con roles (Admin, Organización, Voluntario, Visitante)
- 📦 **Gestión completa** de necesidades, ayudas y puntos de entrega
- 📱 **Diseño responsive** optimizado para teléfonos de gama baja
- 🔄 **Trazabilidad** de ayudas desde el reporte hasta la entrega

## 🛠️ Stack Tecnológico

- **Frontend:** React + Vite + TypeScript
- **Estilos:** Tailwind CSS
- **Base de Datos:** Supabase PostgreSQL
- **Autenticación:** Supabase Auth
- **Mapas:** Mapbox GL JS
- **Gráficos:** Recharts
- **Iconos:** Lucide React
- **Hosting:** Cloudflare Pages
